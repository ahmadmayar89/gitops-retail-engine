## 🚀 Quick Start

### Prerequisites
- Ubuntu 20.04+
- Docker 20.10+
- Kubernetes 1.24+
- Terraform 1.0+
- Node.js 18+

### Installation
```bash
git clone git@github.com:ahmadmayar89/gitops-retail-engine.git
cd gitops-retail-engine
./scripts/setup-dev.sh
```

## 📚 Technologies Used
- Infrastructure: Terraform
- Configuration: Ansible
- Containerization: Docker
- Orchestration: Kubernetes
- CI/CD: GitHub Actions
- Monitoring: Prometheus & Grafana
- Application: Node.js, React, PostgreSQL
